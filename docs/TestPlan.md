# 1. Objective

The purpose of this testing is to verify that the Family Planner application functions correctly, provides a positive user experience, and meets all defined functional requirements.

---

# 2. Scope

The following features are included in testing:

- Add new task
- Complete task
- Delete task
- Clear completed tasks
- Task filters
- Task counter
- Local Storage
- Responsive design
- User Interface

---

# 3. Out of Scope

The following features are not included in testing:

- User authentication
- Backend
- Database
- API communication

---

# 4. Test Types

The following testing types will be performed:

- Functional Testing
- UI Testing
- Usability Testing
- Responsive Testing
- Regression Testing

---

# 5. Test Environment

## Hardware

- Macbook air

## Operating System

- macOS

## Browsers

- Google Chrome

---

# 6. Entry Criteria

Testing can begin when:

- Application is deployed.
- All implemented features are available.
- No blocking issues prevent testing.

---

# 7. Exit Criteria

Testing is considered finished when:

- All planned test cases have been executed.
- Critical defects have been fixed.
- Test Summary has been completed.

---

# 8. Risks

Possible risks during testing:

- Browser compatibility issues
- Responsive layout issues
- Local Storage data loss
- Incorrect task filtering
- Data persistence issues after page refresh

---

# 9. Deliverables

The following documents will be created:

- Test Plan
- Test Cases
- Bug Reports
- Test Summary
- Playwright Tests
